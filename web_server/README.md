# web_server

Scripts for the web server project: transferring files with scp, installing and configuring nginx, redirections and a custom 404 page.

| File | Description |
|---|---|
| 0-transfer_file | Transfers a file to a server using scp |
| 1-install_nginx_web_server | Installs nginx and serves "Holberton School" on port 80 |
| 2-setup_a_domain_name | The domain name pointing to the web server |
| 3-redirection | Adds a 301 redirect for /redirect_me |
| 4-not_found_page_404 | Adds a custom 404 page |
| 5-design_a_beautiful_404_page.html | A designed 404 page |
